Estas respostas explicam os recursos da loja demonstrativa.

Ainda precisa de ajuda? →
Posso comprar os produtos de verdade?

Não. A Nexora Gaming é um projeto acadêmico. Produtos, valores, descontos e informações são ilustrativos.

O carrinho salva os itens?

Sim. A sacola de demonstração usa o armazenamento local do navegador (localStorage), então os itens podem continuar após atualizar a página no mesmo dispositivo e navegador.

O formulário envia uma mensagem real?

Não. O formulário mostra uma confirmação visual para demonstrar a interface, mas não transmite informações a um servidor ou e-mail.

Como encontrar um produto específico?

Abra Produtos, use a caixa de busca e, se desejar, selecione uma categoria para refinar os resultados.

O site funciona no celular?

Sim. O layout é responsivo e adapta a navegação, os cartões e os formulários a telas menores.

Como funciona a lista de favoritos?

Use o coração nos cartões ou no detalhe do produto. A lista é guardada apenas neste navegador e pode ser limpa na página Favoritos.

O orçamento do Setup Lab valida compatibilidade?

Não. O configurador calcula apenas a soma dos preços fictícios selecionados. Ele não verifica compatibilidade, estoque ou disponibilidade real.
