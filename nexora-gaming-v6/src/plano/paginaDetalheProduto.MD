# Plano — Detalhe do produto

**Arquivo:** `src/public/paginas/produto.html`  
**Rota:** `/produto?slug=aurora-x`

Uma página HTML compartilhada apresenta nome, descrição, valor e características com base no parâmetro `slug`. O conteúdo é preenchido pelo JavaScript front-end usando `products.js`, sem colocar marcação HTML no `server.js`.

## V6
- Botão para salvar ou remover o produto dos favoritos.
- Recomendações relacionadas da mesma categoria.
- Atalho para montar uma seleção no Setup Lab.
